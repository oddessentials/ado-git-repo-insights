## Implementation Phases

### Phase 1: Fix Demo Data Generator (FR-001, FR-002, FR-003, FR-010)

**Goal**: Replace flat ratio formulas with distribution-based approach producing credible counts.

#### 1.1 Update reviewer/author formulas in `generate-demo-data.py`

**File**: `scripts/generate-demo-data.py`

**Current** (lines 610-611):
```python
"authors_count": max(1, int(repo_pr_count * 0.3)),
"reviewers_count": max(1, int(repo_pr_count * 0.45)),
```

**New approach**: Use seeded RNG with bounds proportional to PR count:
```python
# Reviewers: at least 1, scale with PR count, cap at rollup total
if repo_pr_count == 1:
    repo_reviewers = 1
else:
    low = max(1, repo_pr_count // 3 + 1)
    high = min(repo_pr_count, rollup_reviewers, max(low, repo_pr_count * 2 // 3))
    repo_reviewers = RNG.randint(low, high)

# Authors: at least 1, scale with PR count, never exceed pr_count
repo_authors = max(1, min(repo_pr_count, RNG.randint(1, max(1, repo_pr_count * 2 // 3))))
```

Apply the same approach to:
- `by_team` entries (lines 637-638)
- `by_team_and_repo` entries (if generated by this script)
- Pass `rollup_reviewers` and `rollup_authors` as caps

**Invariant enforcement**: After generating all breakdown entries, clamp each to the parent rollup's count.

#### 1.2 Regenerate demo data

#### 2.2 Add pre-commit guard

**File**: `.husky/pre-commit`

Add a new section before the UI build trigger section:

```bash
# ── Compiled artifact guard ───────────────────────────────
COMPILED_JS=$(git diff --cached --name-only | grep -E '^extension/ui/.*\.js$' | grep -v 'VSS.SDK.min.js' || true)
if [ -n "$COMPILED_JS" ]; then
    echo "[pre-commit] ❌ Compiled JS file(s) detected in extension/ui/:"
    echo "$COMPILED_JS"
    echo "Compiled output belongs in extension/dist/ui/, not extension/ui/."
    echo "If this is a legitimate hand-written JS file, add it to the allowlist in .husky/pre-commit."
    exit 1
fi
```
