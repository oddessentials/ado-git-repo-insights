# Extension images directory

Place extension icon here:

- `icon.png` - 128x128 PNG icon for the extension

## Icon specification

| Property   | Requirement                                           |
| ---------- | ----------------------------------------------------- |
| Format     | PNG (magic bytes `89 50 4E 47`)                       |
| Dimensions | 128 x 128 px                                          |
| Palette    | Blue-to-purple gradient background, white chart motif |
| Legibility | Must be legible when displayed at 42 x 42 px          |
